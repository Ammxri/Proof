# SynthEHR data in Proof

Proof takes its lab distributions from synthetic biochemistry data generated by SynthEHR (PRD §9, decision D-03). This
page documents the one run that produced them and how the data enter Proof.

> zh: Proof 是评测工具和开放数据集，不是医疗器械，不用于患者诊疗。Proof 衡量的是与公开参考标准的一致性，而非临床真实情况。
> en: Proof is an evaluation tool and open dataset, not a medical device, and not intended for patient care. Proof
> measures agreement with a disclosed reference, not clinical truth.
> de: Proof ist ein Evaluationswerkzeug und offener Datensatz, kein Medizinprodukt und nicht für die
> Patientenversorgung bestimmt. Proof misst Übereinstimmung mit einer offengelegten Referenz, nicht klinische Wahrheit.

## What is and is not in the repository

- **Not in the repository:** SynthEHR itself (program, libraries, source code) and its CSV output. SynthEHR is a GPL
  tool; Proof never runs, imports or ships it (PR-C02). A test checks that no program or code of it is in the
  repository and that Proof starts no program except git.
- **In the repository:** only the lab profiles derived from the CSV, `src/proof_rules/packs/fever/profiles/*.json`.
  Each profile records the generator, the command, the seed, the date and the SHA-256 of the CSV.

## The run

| Item | Value |
|---|---|
| Generator | SynthEHR 2.0.1, Windows command line build, executed only |
| Date | 08.11.2026, 14:33:53 to 14:34:06 UTC, exit code 0 |
| Data set | `Biochemistry`, seed 42, 5000 patients, 100 000 rows |
| Output | `Biochemistry.csv` in `proof/.local/synthehr/` (not versioned) |
| SHA-256 of the CSV | `ae28f46c86b0f8fb4cce67b50c1681f1def2ea4a1b7f668ca72c43e4190be799` |

Command, run in `proof/.local/synthehr/` with the environment variable set for this process only:

```
DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1 SynthEHR.exe -d Biochemistry -s 42 <proof/.local/synthehr> 5000 100000
```

The variable is needed on a computer with German regional settings: without it, SynthEHR 2.0.1 drops the decimal point
and almost every value is implausible (D-03). The SynthEHR folder was the same before and after the run.

## From the CSV to the profiles

```
uv run proof labs build --csv .local/synthehr/Biochemistry.csv --domain fever \
  --generator "SynthEHR 2.0.1" --seed 42 --generated-on 2026-11-08 \
  --command "DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1 SynthEHR.exe -d Biochemistry -s 42 <proof/.local/synthehr> 5000 100000"
```

The method is described in [methodik.md](../methodik.md), section 4. In short: rows with the expected unit, a numeric
value within the physiological bounds and the most common reference range count; every discarded row is counted; the
values are averaged per patient; 21 quantiles describe each status (low, normal, high).

| Fact | Reference range | Rows used / rows | Patients (low / normal / high) |
|---|---|---|---|
| CRP | 0–10 mg/L | 879 / 2199 | 808 (0 / 294 / 514) |
| Creatinine | 44–80 µmol/L | 1804 / 5363 | 1501 (243 / 366 / 892) |
| Bilirubin | 0–21 µmol/L | 1706 / 5469 | 1463 (0 / 902 / 561) |
| Lactate | 0.7–1.8 mmol/L | 100 / 128 | 99 (9 / 31 / 59) |

The case sampler draws a status only if it has at least 21 patients, as many as the profile stores quantiles. Lactate
"low" (9 patients) is therefore not drawn; no active rule needs it. CRP and bilirubin have no "low" status, because
their lower reference limit is 0 (risk RK-02, decision A-67).

## What SynthEHR does not provide

White blood cells (7 of 20 000 rows in the SynthEHR output examined for D-03, without unit) and all vital signs. For
them the fever domain has its own reference ranges with a source, in `packs/fever/sampler.yaml` (D-03, A-67).

## Licence of the output

The SynthEHR README states no licence for the generated data; GPL-3.0 applies to its code. This is an open point
before the first release (D-03, RK-03). The dataset card will state it.
